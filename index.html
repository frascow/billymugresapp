▸ Cómo crear la Nube de Google Drive en 1 minuto (Gratis)

1. Entra en script.google.com con tu cuenta de Google → Nuevo proyecto.

2. Borra el código de ejemplo, pega este script y pulsa Implementar → Nueva implementación → Aplicación web (Ejecutar como: Yo, Quién tiene acceso: Cualquier usuario):

3. Pega la URL https://script.google.com/macros/s/.../exec arriba y pulsa ⬇ index.html para guardar la app ya conectada para toda tu banda.
